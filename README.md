
# Voice Cloning Detection

A student project that analyzes voice authenticity and identifies
potential social-engineering warning signals in audio.

## Features

- Audio upload and voice authenticity prediction
- CNN-based voice classification
- Audio transcription
- Social-engineering warning signals
- Risk scoring and explanations
- Analysis history and report export
- Experimental live microphone analysis
- Simulated trusted-contact alerts

## Technology Stack

- Python and FastAPI
- PyTorch
- Whisper
- Librosa
- FFmpeg
- HTML, CSS, and JavaScript

## Limitations

Predictions and risk scores are estimates, not proof that a voice
is genuine, synthetic, or fraudulent. Performance may vary across
speakers, languages, recording conditions, and audio sources.

Live microphone analysis is experimental and does not directly
intercept phone calls or messaging applications.

## Privacy

Private recordings, transcripts, credentials, personal contact
details, and private analysis records should not be published.
